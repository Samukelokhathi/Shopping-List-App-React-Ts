# 🛒 Shopping List App — React-Task-4

<img src="https://socialify.git.ci/Samukelokhathi/Shopping-List-App-React-Ts/image?language=1&owner=1&name=1&stargazers=1&theme=Light" alt="Shopping-List-App-React-Ts" width="640" height="320" />


A modern, responsive shopping list application built with React and TypeScript. The application allows users to create and manage shopping lists, add and manage items, and keep their shopping information organized through a clean and user-friendly interface.

This project was built to practice React with TypeScript, state management with Redux Toolkit, client-side routing, API communication, and working with a JSON Server backend.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Samukelokhathi/Shopping-List-App-React-Ts.git
```

Navigate into the project

```bash
cd Shopping-List-App-React-Ts
```

Install dependencies

```bash
npm install
```

Start the JSON Server

```bash
npx json-server db.json
```

The JSON Server will be available at:

```text
http://localhost:5000
```

Open another terminal and start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## ✨ Features

* 🔐 User registration and login

* 🛒 Create and manage shopping lists
* ➕ Add items to shopping lists

* ✅ Mark shopping list items as completed

* 📂 Organize shopping list information
